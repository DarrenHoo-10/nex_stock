## 1. 结构

| 位置 | 内容 |
| --- | --- |
| 悬浮导航 | 左侧竖向玻璃条：异动、选股、我的，分隔线下是设置；手机上变成底部悬浮横条 |
| 页头 | 页面标题和说明；右侧是 11-06 运行状态胶囊和白色「助手」按钮 |
| 板块异动 | 市场概况胶囊（含普涨保护），左窗是板块列表，可按类型和状态筛选；右窗显示判定、驱动因素、6 项指标、近 8 日超额收益、代表股票，入口为「在此板块中选股」和「问助手」 |
| 机会选股 | 单个窗口：来源二选一（来自异动板块，或全市场按策略），周期筛选；每只候选列出入选理由、买入条件、失效条件、风险；没有结果时说明原因 |
| 我的股票 | 左窗是账户（总资金、现金、仓位、规则）和持仓/自选列表，可买的排在前面；右窗先是结论大字、一句话计划和 4 个关键数字，再往下是条件计划、股数、换股判断、今天的情况、风险，右侧是价格梯子 |
| 助手 | 右侧悬浮玻璃抽屉，手机上全屏；带上当前股票或板块，提供快捷问题，并说明回答边界 |
| 设置 | 仓位规则（可编辑）、模型（见 4.1 节）、异动阈值（含依据等级）、运行和推送（飞书 Webhook 只显示是否已配置）、数据状态 |
| 运行状态 | 点页头的 11-06 胶囊，查看每一步结果和飞书消息卡片预览 |

## 2. 视觉方向

- 材质：冷色模糊光斑背景加细颗粒，上面是半透明玻璃窗口（`backdrop-filter` 模糊 + 1px 内高光 + 带底色的阴影）。不支持模糊的浏览器退回到不透明的 `#3B4474`。
- 颜色：正文白色，次级文字用白色 84% / 70% / 50% 透明度。强调色只有一个：浅蓝 `#A9CAFF`，用于文字链接和买入区。主按钮是白底藏青字。
- 涨跌：图表柱用 `#FF7468` / `#3CC3B4`，色盲模拟下 ΔE 为 10.9，已用 dataviz 校验脚本通过；柱子同时按零线上下区分，并带正负号。文字用更浅的 `#FFB3AB` / `#7FE0D2`，保证小字在玻璃上能看清。止损和风险统一用琥珀色 `#FFCF6E`，不和涨跌色混用。
- 结论：买入为浅红标签，等待确认为浅蓝，放弃为灰，持有为白底实心。条件计划的「就……」按动作着色：卖出/减仓/清仓为琥珀，买入为蓝，其他为白。
- 字体：系统字体（SF Pro / 苹方，Windows 上是 Segoe UI Variable / 微软雅黑），数字一律等宽，保证价格对齐。结论用 76px 粗体渐变字。
- 布局：详情窗按「结论 → 关键数字 → 计划 + 价格梯子」从上到下排列，最重要的信息在第一屏。排版按详情窗自身宽度（容器查询）切换：窗口窄于 780px 时价格梯子移到计划下方，窄于 500px 时条件计划改成上下两行。

## 3. 动效

所有动效都是对用户操作的反馈，系统设置为「减少动态效果」时全部关闭。

- 弹簧曲线：CSS `linear()` 模拟弹簧，不支持的浏览器退回到 `cubic-bezier(.2,.9,.25,1)`。
- 共享布局过渡（FLIP）：导航的选中底块、分段控件的滑块、列表的选中行、设置分类的选中项，在切换时从旧位置滑到新位置。
- 数字滚动：账户数字、关键数字和股数在切换股票或修改规则时，从旧值滚到新值。
- 入场：切换页面时窗口依次浮现；切换股票时详情内容依次出现；切换周期时只刷新条件计划。
- 图表：价格梯子的轴线先画出，再依次出现各价位；超额收益柱从零线长出。
- 其他：抽屉和弹层用弹簧滑入，按钮按下时轻微缩小，鼠标在玻璃窗上移动时有跟随的柔光。

## 4. 关键交互

- 股数按核心功能说明 5.3 节的公式实时计算：取「单只上限、总仓位、现金」三者的最小值，再按每手 100 股（科创板最少 200 股）向下取整。展开「怎么算的」可以看到每一步。
- 仓位规则（止损幅度、总仓位、最多持有只数、止损方式）在设置里修改，保存后股数、止损价和换股判断立即重算，不写死。
- 持仓已达上限时，自选股不再给股数，改为提示去看换股判断。换股要同时满足两个条件，默认结论是不换。
- 「记录买入」会预填买入价，保存时自动从现金里扣掉这笔金额。「演示：空仓，现金 100,000」用来复现核心功能说明里的例子：47.00 买 2,100 股，止损 42.30，到止损亏 9,870 元。
- 手机端：列表和详情分两屏，详情先展示结论和行动计划，价格梯子放在后面；导航在底部。

### 4.1 模型设置

按用途选模型，不按技术字段排列。每个界面项都对应后端现有的配置，没有新增配置项：

| 界面 | 现有配置 | 说明 |
| --- | --- | --- |
| 次日计划 | `LITELLM_MODEL` | 16:00 分析用的主模型，必填 |
| 备用模型 | `LITELLM_FALLBACK_MODELS` | 有序列表，可上移、移除；不能包含主模型，换主模型时自动去掉重复项 |
| 助手 | `AGENT_LITELLM_MODEL` | 默认「跟随次日计划模型」，即留空 |
| 截图识别 | `VISION_MODEL` | 识别持仓、自选截图里的股票 |
| 温度 | `LLM_TEMPERATURE` | 0 到 2，保存时校验 |
| 渠道 | `LLM_CHANNELS` 及各渠道的 `_PROTOCOL`、`_BASE_URL`、`_API_KEY`、`_MODELS` | 名称、协议、接口地址、密钥、模型列表 |

- 选择框按渠道分组，选项值是 `渠道/模型`；连接失败的渠道在分组名后标出。
- 用途改动先进草稿，点「保存模型设置」才生效，可以放弃修改；渠道的增、改、删在弹层里单独保存。
- 密钥不回显：已配置时输入框显示「已配置，留空表示不修改」，列表里只写「密钥已配置」或「无需密钥」。
- 正在被次日计划、助手或截图识别使用的渠道不能删除，也不能删掉正在使用的模型，会提示先换模型；被删掉的模型会自动从备用列表移除。
- 「测试连接」显示测试中、正常（带耗时）或连接失败；主模型所在渠道连接失败时，表单上方给出提示。
- 「上次运行」表格列出每一步的调用次数和实际使用的模型，回退记录写明原因（例如等待 60 秒超时）和改用的模型。助手每条回答的依据行也写出所用模型。

## 5. 验证

- 1366px、1024px、375px 和 320px 下，各页面、持仓弹层、运行弹层、渠道弹层都没有横向滚动，控制台没有报错。
- 模型设置已走查：添加、排序、移除备用模型，换主模型去重，温度越界报错，添加渠道（名称重复、缺模型名报错，地址去掉协议头和末尾斜杠），删除在用渠道被拦下，测试连接的三种状态。
- 已核对核心功能说明里的示例数字：空仓例子为 2,100 股、98,700 元、止损 42.30、亏 9,870 元，再跌停时为 38.07 / 18,753 元；宁德时代为 300 股、78,600 元；持仓立讯精密止损 36.18，明天跌停价 37.13。
- 风格稿图片只保存在本机被忽略的目录里，没有放进仓库。
- 只有深色玻璃一种外观，没有浅色模式；没有接入真实数据。
