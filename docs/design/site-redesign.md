# NEX STOCK 全站交互重设计

日期：2026-11-07。状态：**设计原型，非生产实现**。

## 目标与边界

用户希望围绕“根据当日个股数据与相关信息，分析投资策略”重做全站交互，并明确选择先交付全站可点击设计稿，再考虑生产落地。

- 入口：[打开全站原型](site-redesign.html)。单个 HTML 内含样式、脚本和 fixture，直接在浏览器打开即可使用，不依赖 CDN 或构建步骤。
- 此前的[个股当日策略稿](stock-research/stock-research-report.html)保留为详细页面参考；全站稿重新统一了导航、主题与操作反馈。
- 不修改 `apps/dsa-web/`、后端、桌面端或生产配置；不调用模型、行情、通知、认证或账户 API。
- 所有公司、代码、行情、消息、账户和回复都是虚构。样例交易日固定为 2026-10-23，不伪装成当前实时行情。
- 状态只保存在当前页面内存，刷新恢复样例。用户不应输入真实密码、密钥、账户或个人交易信息。

## 信息架构

主流程：**发现机会 → 查看个股当日策略 → 跟踪自选与持仓 → 复盘结果**。

首页从“历史报告为中心”改成“今日需要关注的变化”。报告、来源与诊断是支持决策的证据层，不先要求用户阅读完整公司研究文章。

## 视觉系统与组件参考

- 浅色采用冷灰背景 `#f1f4f6`、白色内容面、青色操作强调 `#246c67`；深色采用 `#151d24` / `#1e2932` 与 `#80c6b9`。
- 中文优先使用本机 `PingFang SC` / `Microsoft YaHei`，拉丁字母使用 `Segoe UI`；不加载在线字体。表格数值采用等宽数字，不以装饰性大数字挤占决策空间。
- 导航按用途分组；桌面端双栏布局，手机端单一主导航。自选与筛选表格在手机上变为可直接操作的条目，而不是隐藏操作列的宽表。
- 只对选中、按压和开关提供短过渡；移除整页自动淡入，避免连续对比股票时反复闪动。支持 `prefers-reduced-motion`，不采用粒子背景、鼠标追光、数字滚动或持续价格动画。
- 图表颜色另用已校验的蓝/橙标识支撑与压力，辅以实线/虚线。蜡烛红涨绿跌并辅以空心/实心；保留键盘/点击/悬停 OHLC 与同窗口数据表。

## 本轮细调：减少阅读负担，保留决策依据

- 首页把自选列表前置，以一条紧凑风险提示替代重复说明。点击股票名称，桌面右侧同步策略摘要；980 像素及以下在对话框查看同一摘要，不需要先离开列表。
- 摘要同时给出当前判断、回踩区、压力区和风险线；完整策略、提醒、追问都带入选中股票。风险过滤后的列表与摘要保持一致，关闭移动摘要恢复到原股票按钮。
- 个股策略先展示动作与主要理由，支持/反对依据按需展开；详细论据仍保留，不用收起内容掩盖证据缺口。
- 手机端将行动预案放在图表和新闻之前。375×812、初始折叠状态下，预案起点从约 1,824 像素前移到约 597 像素，判断摘要高度从约 435 像素缩短到约 218 像素；数字是当前样例的页面测量，不是所有设备的固定布局保证。
- 回踩、突破、风险三种场景一次展开一项，收起时仍显示关键价位；顶部区段导航与“在图上看”可直接定位相关证据。切换持仓、周期或图表时保留展开状态和控件焦点。
- 统一页面标题与导航名称，移除空操作列，提高表格字号；修正涨跌颜色被表格通用文字样式覆盖的问题，正负号继续保留，避免只靠颜色传达涨跌。
- 修复移动摘要进入追问后旧对话框未关闭的问题；跳转后聊天页可操作，仍使用同一股票上下文。

## 实际可走通的体验路径

### 发现机会到策略

1. 从工作台进入发现机会，选题材与策略。
2. 开始演示筛选，任务中心显示排队、处理中、完成；点击“推进演示”切换步骤，不伪造后台进度。
3. 结果保留生成时的条件；调整表单后查看已有结果，会提示条件不同。
4. 候选直接加入自选或发起深入分析，完成后打开同一股票策略。
5. 从策略建立价格提醒，手动测试仅判断样例是否命中，不宣称已通知或真实监控启动。

### 持仓到风险应对

1. 全部账户只读，选择具体账户才允许写入演示记录。
2. 交易表单验证正数、数量和超额卖出；CSV 固定样例先预览再确认。
3. 持仓进入策略时保留“已持仓”上下文。
4. 信号重评先选择偏好、生成预览，再确认保存；缺少证据的积极方案被护栏阻止。
5. 带着股票继续追问，答复固定且明确标记模拟；支持停止、切换会话和导出。

### 历史到复盘

1. 选择历史日期，查看当时的判断，不用最新价格补齐历史缺口。
2. 进入复盘，切换观察窗口；窗口未满显示“观察期不足”，不算零收益。
3. 区分价格变化与真实交易收益，没有成交/费用/滑点不计算交易收益。

## 状态、无障碍与安全边界

- 页脚“状态演示”统一提供正常、加载、空、失败、部分数据视图；它是设计切换器，不是生产状态开关。
- 共享任务中心演示失败、重试、重复任务抑制，以及从任意页回到结果。
- 搜索支持 Ctrl/Cmd+K、上下选择、Enter；手机导航为单一抽屉。
- 对话框有标签、焦点约束、Esc 关闭和焦点恢复；打开时背景 inert。保留跳到主内容链接。
- 配置草稿跨分类保留；站内导航、hash 变化和刷新有未保存保护。主题可预览，撤销恢复原状态。
- 用户输入以文本或经过 HTML 转义后显示；对话不会执行输入的标记或脚本。
- 登录只验证演示字符长度；不接收或持久化真实凭据。文件导出仅包含演示文本。
