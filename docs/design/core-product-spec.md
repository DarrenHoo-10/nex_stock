# NEX STOCK 核心功能说明（讨论稿）

日期：2026-11-07。状态：**讨论稿；API 层与 Web 页面已实现（见 [次日计划 API 与 Web 入口](../daily-plan-api.md)），后端服务尚未实现**。本文先确定产品要做什么，视觉设计在功能确认后重新进行。

## 1. 定位与已确认的范围

一个帮助个人投资者在 **A 股收盘后制定次日交易计划** 的工具，回答四个问题：

1. 最近哪些板块在异动？
2. 哪些股票近期可能有机会？
3. 我关注和持有的股票，明天该买、该卖还是等待？买卖多少？
4. 对上面任何结论，我还能继续问。

已确认的决定：

| 事项 | 决定 |
| --- | --- |
| 市场 | 只做 A 股 |
| 分析时点 | 收盘后生成次日策略；不做盘中实时推荐 |
| 策略周期 | 短线（1–5 个交易日）与波段（2–4 周）都提供 |
| 仓位 | 需要给出具体仓位建议；默认止损 10%、总仓位 100%、最多持有 1 只，均可配置 |
| 交互入口 | 命名为“助手” |
| 生成时间 | 每个 A 股交易日 16:00 自动生成，时间可配置 |
| 分析范围 | 全部自选股和持仓股 |
| 推送 | 生成完成后通过飞书群机器人 Webhook 推送 |

不做的事：自动下单、盘中盯盘推送、收益承诺。所有建议都是条件式计划，最终是否交易由用户决定。

## 2. 导航与主流程

一级入口只保留三个页面和一个全局助手：

```
板块异动  →  机会选股  →  我的股票
   └──────────── 助手（任意位置唤起，带入当前上下文）────────────┘
```

每日使用路径：

1. 收盘后打开 **板块异动**，看哪些板块在启动、持续或退潮。
2. 点进某个板块，或直接进入 **机会选股**，看候选股与入选理由。
3. 把感兴趣的股票加入自选，或录入已有持仓。
4. 在 **我的股票** 查看每只股票的次日策略：买入/卖出条件、价位和股数。
5. 有疑问时打开 **助手** 追问。

设置、数据状态、模型用量等放入个人菜单，不占主导航。原有信号、提醒、复盘、历史记录不作为独立入口，后续视需要并入个股详情。

## 3. 板块异动

### 3.1 调研结论

2026-11-07 查阅约 18 个来源（东方财富百科与 Level-2 说明、券商金工研报、情绪周期统计与实践文章等），结论如下：

- **东方财富、同花顺都没有公开“板块异动”的数值规则。** 东方财富的“板块异动”是盘中统计板块内出现异动的个股家数，不能直接用于收盘后判断。
- 网上流传的阈值大多是 **个股或全市场** 层面的经验值，没有找到板块级的回测数据。下面的板块默认值多为由这些口径推导，**上线后需要用历史数据校准**。
- 多份研报指出：A 股行业短期动量常出现反转。因此“持续走强”只描述过去的状态，**不作为买入信号**。
- 主力资金为各数据商按委托单大小自行估算，交易所不公布，口径不一，**只作辅助展示，不作判断条件**。

两条基本原则：

1. **用成交额，不用成交量。** 板块内股价差异大，合计股数没有意义。
2. **以全部板块中的排名为主，绝对涨幅为辅。** 板块数量和市场状态每天在变，排名比固定涨幅更稳；绝对下限用于避免平淡市场里也报出异动。

### 3.2 默认参数

全部为配置项。“依据”一列说明证据强弱：**中** = 有多个来源支持的通行口径；**低** = 单一来源或经验说法；**推断** = 没有直接来源，由相近口径推导。

| 参数 | 默认值 | 依据 |
| --- | --- | --- |
| 温和放量 | 成交额 ≥ 近 5 日均值 1.5 倍 | 中：个股“量比 1.5–2.5 温和放量”口径移植到板块 |
| 明显放量 | 成交额 ≥ 近 5 日均值 2.5 倍 | 中；板块为汇总值，波动小于个股，可能偏严 |
| 强势排名 | 当日超额收益排在全部同类板块前 10% | 中：对应相对强度 RPS ≥ 90 |
| 弱势排名 | 当日超额收益排在后 10% | 推断：与强势对称 |
| 绝对超额下限 | 行业 +1.5%，概念 +2.5% | **推断，必须回测校准** |
| 比较基准 | 中证全指；同时显示相对全部板块中位数的超额 | 推断：沪深 300 偏大盘，会高估小盘题材 |
| 上涨家数占比 | 强 ≥ 70%，弱 ≤ 30% | 低：全市场宽度口径移植 |
| 板块效应（概念） | 板块内涨停 ≥ 3 家 | 低 |
| 主线（概念） | 涨停连续 2 日 ≥ 5 家，最高连板 ≥ 3，持续 ≥ 5 天 | 低 |
| 炸板率预警 | 板块内炸板率 ≥ 40%，且触及涨停 ≥ 5 家才计算 | 中（全市场长期均值约 30%，下行期约 40%）；板块样本门槛为推断 |
| 持续确认 | 连续 3 个交易日跑赢基准 | 低 |
| 退潮成交 | 成交额低于近期峰值的 50% | 低 |
| 普涨日降权 | 全 A 涨幅 ≥ 2% 时，涨停与上涨家数信号降权，只看排名 | 低到中 |
| 最少成分股 | 10 只；概念成分超过 800 只视为宽基，不参与 | 推断 |
| 单股驱动 | 单只股票贡献超过板块涨幅 50% 时标注“单股驱动”，不报异动 | 推断 |
| 新概念冷却 | 新概念上线 10 个交易日内只记录，不判“首次启动” | 推断 |
| 重复概念合并 | 成分股重合度（Jaccard）≥ 0.6 的概念合并展示 | 推断 |
| 统计剔除 | ST、退市整理、无涨跌幅限制的新股和复牌股；一字板单列 | 中：与多数涨停统计口径一致 |

行业板块不使用涨停类条件；概念板块额外使用。

### 3.3 异动类型判定

下文“强日”指当日处于强势排名且超过绝对超额下限；“弱日”指当日处于弱势排名。

| 类型 | 判定条件 |
| --- | --- |
| **首次启动** | 前 5 日没有强日，且近 5 日超额不在前 30%；当日为强日，成交额 ≥ 5 日均值 1.5 倍，上涨占比 ≥ 60%。概念另需涨停 ≥ 3 家，且非单股驱动、不在新概念冷却期 |
| **持续走强** | 连续 3 日跑赢基准，其中至少 2 天为强日；近 5 日超额排在前 10%，成交额占全市场比例未连续下降。概念满足“主线”条件时标注为主线 |
| **高位分歧** | 处于持续走强，或近 5 日超额在前 10%；当日满足任意 2 条：超额 ≤ 0 或上涨占比 ≤ 50%；放量但超额 ≤ 0（放量滞涨）；炸板率 ≥ 40%；涨停数比前一日减少一半以上。成交额不低于前一日且仍有涨停时，标注“有承接”，次日再判断方向 |
| **退潮** | 近 10 日出现过持续走强或高位分歧；连续 2 日满足任意 2 条：超额 < 0；涨停 ≤ 1 家；成交额低于峰值 50%；上涨占比 ≤ 30%；近 5 日超额排名跌出前 50% |
| **异常下跌** | 当日为弱日，超额 ≤ 负的绝对下限，成交额 ≥ 5 日均值 1.5 倍，上涨占比 ≤ 30%。概念另需跌停 ≥ 3 家，或跌幅超过 7% 的个股占比 ≥ 30%（推断） |

### 3.4 校准计划

上述阈值上线前用历史数据做一次离线校准：统计各类型出现的频率（例如每天报出多少个“首次启动”），以及判定后 1、3、5 日的板块表现。频率过高或过低时调整阈值。校准只使用已有或单次采样的历史数据，不反复请求外部行情接口。

主要参考：[东方财富百科·量比](https://baike.eastmoney.com/item/%E9%87%8F%E6%AF%94)、[东方财富 Level-2 资金流说明](https://emdesk.eastmoney.com/pc_activity/Pages/VIPTrade/pages/link/zjl.html)、[三才聚·炸板率统计](https://sancaiju.cn/post.php?id=134)、[XtradingTime·主线识别](https://www.xtradingtime.com/articles/identify-main-sector/)、[开源证券·行业轮动 3.0](https://aigc.idigital.com.cn/djyanbao/%E3%80%90%E5%BC%80%E6%BA%90%E8%AF%81%E5%88%B8%E3%80%91%E5%A4%A7%E7%B1%BB%E8%B5%84%E4%BA%A7%E9%85%8D%E7%BD%AE%E7%A0%94%E7%A9%B6%E7%B3%BB%E5%88%97%EF%BC%8811%EF%BC%89%EF%BC%9A%E8%A1%8C%E4%B8%9A%E8%BD%AE%E5%8A%A83.0%EF%BC%9A%E8%8C%83%E5%BC%8F%E3%80%81%E6%A8%A1%E5%9E%8B%E8%BF%AD%E4%BB%A3%E4%B8%8EETF%E8%BD%AE%E5%8A%A8%E5%BA%94%E7%94%A8-2024-12-10.pdf)。券商 PDF 与部分统计页只读到摘要，未核对全文。

### 3.5 页面输出

- 异动板块列表：名称、类型、当日与近 5 日涨幅、成交放大倍数、涨停家数、一句话原因。
- 板块详情：
  - 驱动因素：消息、资金或业绩；无法确认时明确写“原因未明”。
  - 代表股票：领涨股、成交额最大股、跟涨股。
  - 持续性判断及其依据。
  - 入口：“在此板块中选股”“问助手：这个板块还能持续吗？”。

## 4. 机会选股

### 4.1 候选来源

- **从异动板块选**：在选中板块的成分股中筛选。
- **全市场按策略选**：例如缩量回踩、放量突破、超跌反弹、资金热度、动量质量等。

每次结果都保留运行时的条件、交易日和数据来源，修改条件不改写旧结果。

### 4.2 短线与波段

| | 短线（1–5 日） | 波段（2–4 周） |
| --- | --- | --- |
| 侧重 | 板块热度、量价突破、资金 | 趋势结构、回踩支撑、基本面不拖后腿 |
| 典型策略 | 放量突破、热点龙头跟随 | 缩量回踩、趋势延续、超跌修复 |
| 止损 | 较紧 | 较宽，以趋势破坏为准 |

候选股可同时符合两种周期，也可只符合其一。

### 4.3 每只候选股的输出

- 入选理由（量价、板块、资金、消息分别说明）
- 适合的周期：短线 / 波段 / 两者
- 买入条件：什么情况出现才值得买（如“回踩 27.5–28.0 元缩量企稳”）
- 失效条件：什么情况下机会作废
- 主要风险
- 操作：加入自选、查看次日策略、问助手

候选股表示“值得重点观察”，不是“预计会涨”。

## 5. 我的股票：自选与手动持仓

### 5.1 录入

**账户资金**（用于计算仓位，必填一次，可随时修改）：

- 总资金
- 可用现金

**持仓**（手动录入）：

| 字段 | 是否必填 |
| --- | --- |
| 股票代码 | 必填 |
| 持仓数量 | 必填 |
| 持仓成本 | 必填 |
| 买入日期 | 选填；用于判断 T+1 是否可卖 |
| 计划周期 | 选填：短线 / 波段；不填时两种都给 |

**仓位规则**（保存在配置中，可在设置页修改；代码不写死任何数值）：

| 规则 | 默认值 | 说明 |
| --- | --- | --- |
| 止损幅度 | 10% | 从买入价或持仓成本起算的最大跌幅 |
| 总仓位上限 | 100% | 所有持仓市值占总资金的上限 |
| 最多持股数 | 1 只 | 当前策略为集中持有一只股票 |
| 单只股票仓位上限 | 100% | 由总仓位上限 ÷ 最多持股数推出，也可单独设置 |
| 单笔最大亏损 | 不单独设置 | 按“仓位 × 止损幅度”推出；默认满仓时约为总资金的 10% |

用户以后改成分散持有时，只需修改最多持股数或单只上限，计算与界面自动适配。

第一版只需要“当前持仓快照”。逐笔交易流水、分红送转、CSV 导入放到后续版本，避免一开始录入负担过重。

### 5.2 每日分析内容

每只股票每天收盘后生成一份次日计划：

1. **结论**
   - 未持仓：买入 / 等待确认 / 放弃
   - 已持仓：持有 / 加仓 / 减仓 / 清仓
2. **当日情况**：涨跌幅、量能、相对板块与大盘的强弱、关键消息
3. **关键价位**：支撑区、压力区、止损线、止盈或减仓位
4. **次日条件计划**。以总资金 10 万元、默认规则（满仓一只、止损 10%）为例：
   - 回踩 46.8–47.2 元缩量企稳，按 47.0 元买入 → 2,100 股（98,700 元，占总资金 98.7%）
   - 止损价 = 47.0 × 0.9 = 42.30 元；收盘跌破即次日卖出全部，按止损价计算亏损 9,870 元
   - 未回踩、直接放量站上 49.6 元 → 不追高，等待新的回踩点
   - 已持有时：放量站上 49.6 元继续持有；冲高至 52 元附近未放量 → 减半
5. **短线 / 波段** 两个周期分别给出价位和仓位；结论可以不同
6. **数据缺口**：缺少的数据会降低结论强度，并明确写出

### 5.3 仓位计算

仓位建议必须可以解释，按规则计算，不由模型随意生成。模型负责判断“买不买、在什么价位买”，股数由规则算出。

**止损价**

```
止损价 = 买入价（或持仓成本）× (1 − 止损幅度)      默认：× 0.9
```

- 默认严格按你设定的固定比例止损。
- 分析给出的技术支撑位只作参考：支撑位高于止损价且被跌破时，提示“技术形态转弱”，由你决定是否提前处理；支撑位低于止损价时，提示“止损会在支撑之前触发”。
- 止损方式也做成配置项：固定比例（默认）或“固定比例与技术位取较近者”。

**买入股数**

```
按单只上限 = 总资金 × 单只仓位上限 ÷ 买入价 − 已持股数
按总仓位   = (总资金 × 总仓位上限 − 当前持仓市值) ÷ 买入价
按现金     = 可用现金 ÷ 买入价

建议股数 = 三者最小值，按 A 股申报单位向下取整
```

- 主板、创业板以 100 股为单位；科创板单笔至少 200 股。
- 结果不足一个申报单位时，提示“按当前规则不建议买入”，不硬凑。
- 已达到最多持股数时，新股票不再给“买入”，改为评估是否 **换股**（见 5.4）。
- 同时显示：占总资金比例、按止损价计算的最大亏损金额、操作后总仓位。

**卖出**

- 收盘价跌破止损价：次日卖出全部，不讨论“再等等”。
- 止盈、减仓按计划价位给出比例（如“减半”“清仓”），并换算为股数。卖出允许零股一次性卖出。

### 5.4 换股判断（最多持股数已满时）

默认只持有一只股票，因此每天的核心问题往往是：**继续持有，还是换成更好的候选？**

计划中需要单独给出这一项：

- 当前持仓的次日计划（持有 / 减仓 / 清仓）
- 最值得替换的候选股（来自机会选股和自选股），以及它比当前持仓好在哪里
- 换股条件：例如“当前持仓收盘破位，且候选股回踩企稳”，两个条件都满足才换
- 换股成本：T+1 限制、两边的止损位置、换股后的最大亏损

没有足够明显的优势时，默认结论是“不换”，避免频繁换股。

### 5.5 10% 止损的风险提示

- 主板一个跌停约为 10%，止损可能在跌停当天无法成交，次日继续低开时实际亏损会超过 10%。
- 创业板、科创板单日最大跌幅 20%，止损在一个交易日内就可能被跳空越过。
- 满仓一只股票时，单笔亏损直接对应总资金的同等比例。计划中会显示“按止损价计算的亏损金额”和“跌停情况下的亏损金额”两个数字。

这些提示只用于说明风险，不改变用户设置的规则。

### 5.6 A 股交易约束

- **T+1**：当日买入的股票次日才能卖出；未填写买入日期时提示用户确认。
- **涨跌停**：主板 ±10%，创业板、科创板 ±20%，北交所 ±30%，ST ±5%。次日计划中的价位超出涨跌停范围时标注无法成交。
- **停牌**：停牌股票不生成次日交易计划，只显示复牌后需关注的事项。

## 6. 助手

### 6.1 形态

- 全局入口，从右侧展开；手机端为全屏。
- 在板块、候选股、个股策略、持仓卡片上点“问助手”时，自动带入对应上下文。
- 也可以不带上下文直接提问，例如“今天哪个板块最值得关注？”。

### 6.2 自动带入的上下文

- 当前板块或股票
- 当日分析结论、关键价位、仓位计算过程
- 用户的持仓数量、成本、账户资金和仓位规则
- 相关新闻和数据缺口

### 6.3 常用问题

- 如果明天低开 / 高开怎么办？
- 按我的成本，止损应该放在哪里？
- 现在加仓风险大吗？
- 这个板块还能持续吗？
- 为什么不建议买？

### 6.4 边界

- 回答必须基于同一份当日数据；没有分析过的股票，先触发分析，不凭空回答。
- 不改写已生成的次日计划。用户要求调整仓位规则时，提示到设置中修改并重新计算。
- 第一版助手只回答问题，不代替用户执行加入自选、修改持仓等操作。

## 7. 每日自动运行与飞书推送

### 7.1 运行时间

- 每个 **A 股交易日** 16:00 自动运行，时间可配置。
- 按交易日历判断，而不是按“周一到周五”：法定节假日不开市不运行，调休上班的周六、周日也不开市，同样不运行。
- 运行顺序：板块异动 → 机会选股 → 全部自选股与持仓股的次日计划 → 换股判断 → 推送。
- 单只股票分析失败不影响其他股票，推送中列出失败的股票和原因。
- 16:00 时部分数据可能尚未更新完整（例如部分资金流、龙虎榜类数据通常更晚发布）。未更新的数据标记为缺失，不当作“没有异常”，并在推送中注明。

### 7.2 分析数量

- 每天分析全部自选股和持仓股，不设数量上限。
- 自选股较多时，运行时间和模型调用量随之增加。页面和推送显示本次耗时、成功与失败数量，便于你判断是否需要精简自选。

### 7.3 飞书推送

**渠道**：飞书群自定义机器人 Webhook。复用现有配置项：

- `FEISHU_WEBHOOK_URL`：机器人 Webhook 地址
- `FEISHU_WEBHOOK_SECRET`：开启“签名校验”时填写
- `FEISHU_WEBHOOK_KEYWORD`：开启“关键词”校验时填写，系统自动加在消息前

地址和密钥只保存在本机配置中，不写入代码、文档示例或日志。

**格式**：飞书消息卡片（Markdown 渲染）。现有发送逻辑已支持签名、关键词和超长消息分段（默认约 20KB 一段）。持仓结论放在第一屏，避免被分段推到后面。

**内容**：推送是一份简明摘要，完整内容在网页查看：

1. **今日结论**：持仓股明天怎么做（持有 / 减仓 / 清仓 + 关键价位 + 股数）
2. **换股判断**：是否有值得替换的候选，以及换股条件
3. **自选股**：每只一行，写明结论与触发价位；可以买入的排在前面
4. **板块异动**：前几名异动板块，各附一句原因
5. **数据提醒**：缺失数据、失败股票
6. 查看完整计划的网页链接

推送失败不影响计划生成；网页中保留计划，并显示推送状态。
